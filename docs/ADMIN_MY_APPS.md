# 📱 Управление своими приложениями (Админка)

Теперь можешь добавлять и обновлять свои приложения прямо в админке, без использования консоли!

## 🚀 Быстрый старт

1. Открой админку: `/admin/my-apps`
2. Нажми на вкладку **"➕ Добавить"**
3. Заполни форму:
   - **Название** (обязательно) - "Мой Калькулятор"
   - **Package ID** (обязательно) - "com.example.calc"
   - **Категория** (обязательно) - выбери из списка
   - Остальное опционально

4. Нажми **"Добавить приложение"**
5. ✅ Готово! Приложение появится на сайте через 1-2 минуты

## 📋 Вкладка "Список"

Здесь видишь все свои приложения:
- 📌 **Название и разработчик**
- 📊 **Версия**
- 📦 **Package ID**
- 🔧 **Действия**:
  - **Править** - редактировать (скоро)
  - **Удалить** - удалить из каталога

## ➕ Вкладка "Добавить"

### Обязательные поля
| Поле | Пример | Что это |
|------|--------|--------|
| Название | "My Photo App" | Как приложение называется |
| Package ID | "com.example.photo" | Уникальный ID Android приложения |
| Категория | "MEDIA" | В какую категорию добавить |

### Опциональные поля (заполни если есть)

| Поле | Пример | Зачем |
|------|--------|-------|
| Разработчик | "John Doe" | Имя разработчика |
| Версия | "1.2.3" | Текущая версия |
| Размер | "5.2 MB" | Размер APK |
| Min Android | "8.0" | Минимальная версия Android |
| URL иконки | "https://..." | Ссылка на иконку 512×512 |
| URL для скачивания | "https://..." | Где скачать APK |
| SHA-256 | "abc123..." | Контрольная сумма для безопасности |


## 🔄 Обновление приложений

Позже появится кнопка **"Править"** в списке, которая позволит:
- Обновить версию
- Загрузить новую иконку
- Изменить URL для скачивания
- Отредактировать все поля

А пока можешь:
1. Удалить приложение
2. Добавить его заново с новыми данными

**Или** отредактируй вручную в `data/custom-apps.json` (для продвинутых пользователей)

## 📍 Где это появляется на сайте?

После добавления приложение:
- 📱 Появляется на главной странице в соответствующей категории
- 🌍 Доступно во всех 4 языках (en, ru, tr, uz)
- 🔍 Оптимизировано для поиска в Google
- 📊 Считается в общей статистике каталога

## ⚙️ Технические детали

### Где хранятся приложения?
- Файл: `data/custom-apps.json`
- Это JSON с массивом приложений
- Автоматически обновляется при добавлении через админку

### Когда появляются на сайте?
- **Примерно через 1-2 минуты** после добавления
- Сайт пересобирается автоматически
- Если долго ждёшь → пересобери вручную: `npm run build`

### Формат данных
```json
{
  "slug": "my-photo-app",
  "custom": true,
  "package_id": "com.example.photo",
  "category": "MEDIA",
  "developer": "You",
  "version": "1.0.0",
  "size": "8.5 MB",
  "icon_url": "https://...",
  "download": {
    "type": "direct",
    "url": "https://...",
    "checksum_sha256": "abc123...",
    "updated": "2026-09-10"
  }
}
```

## 🎯 Советы

1. **Большая иконка** (512×512 px) - будет красиво смотреться
2. **Правильный Package ID** - без ошибок, иначе сайт может не показать
3. **URL для скачивания** - желательно добавить, чтобы можно было скачать
4. **SHA-256** - опционально, но добавь если есть (безопасность)
5. **Версия** - обновляй при каждом релизе новой версии

## ❓ Часто задаваемые вопросы

**Q: Сколько приложений можно добавить?**
A: Сколько хочешь! Можешь добавить 5, 20, 100+ приложений.

**Q: Можно ли удалить приложение?**
A: Да, нажми кнопку "Удалить" в списке. Исчезнет с сайта через 1-2 минуты.

**Q: Как обновить версию приложения?**
A: Позже появится кнопка "Править". А пока удали и добавь заново с новой версией.

**Q: Что если APK файла ещё нет?**
A: Оставь поле "URL для скачивания" пустым. Добавишь позже.

**Q: Как добавить несколько языков?**
A: Описание автоматически генерируется на 4 языках! Ты можешь редактировать вручную в JSON позже.

**Q: Будут ли обновления автоматическими?**
A: Нет, нужно вручную обновлять версию каждый раз через админку.
